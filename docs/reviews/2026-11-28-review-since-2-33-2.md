# Review of the changes since 2.33.2

Date: 2026-11-28. Range: `v2.33.2` (a8677a2) to `main` at bfdac26.

Scope: everything merged since the release. The docs PRs #536 to #538, the harness fixes #539 to #542 (the Hermes incognito leak, Oh My Pi 19.2 tool commands, the harness references and the Hermes scan pin), the client package changes #543 to #545 (the instructions copy, the `Conversation` tracker, `ainvoke_with_reminder` and `generateTextWithReminder`, the OpenAI Responses format, the argument drift test) and the client README docs #546. Questions: correctness, security, Python and npm parity, test gaps and docs drift. The incognito launcher and the client packages' public API were also reviewed by a second reviewer.

## Summary

The release is in good shape apart from two real bugs and one incomplete security fix. The Hermes gateway check from #542 misses gateways in three of their live states and the host-wide gateway that serves every profile, so incognito could still reach Hivemind there. `generateTextWithReminder` sends the reminder turn without the task's tool calls on AI SDK 7, the only version the npm package supports. Both reminder helpers also send the reminder after a run that paused for approval. Everything else checked out: the reminder rule matches the Stop hook, the drift test covers every tool argument, the text copies are pinned, and the docs links and anchors still resolve after the voice pass.

## Findings

### 1. Medium (security): the Hermes gateway check misses live gateways

`plugins/hivemind/bin/hivemind-incognito:74` refuses only when `gateway_state.json` says `"running"`. Hermes v0.23.4, the pinned version, also writes `starting`, `degraded` and `draining` while the process is up. It writes `degraded` when a messaging platform failed for good, and the gateway then stays up for local clients (`gateway/run_startup.py`, `_serving_state`). Only `stopped` and `startup_failed` mean it exited.

The launcher also reads only the profile's own state file (`hivemind-incognito:190`). v0.23.4 has one multiplexing host gateway per OS user that serves every profile (`gateway/host_attach.py`), with its record in `~/.local/state/hermes/gateway-locks/host-gateway.json` (or `$XDG_STATE_HOME`, or `$HERMES_GATEWAY_LOCK_DIR`). A `-p work` session attaches to it, and the profile's own state file does not exist.

Scenario: a gateway with a Telegram adapter parked as fatal sits in `degraded`. `hivemind-incognito hermes` sees "not running", and the session runs inside the old gateway with Hivemind on.

Fix: refuse while the pid is live and the state is anything but `stopped` or `startup_failed`, and also while the host record names a live pid (fail closed). Fixed in #547.

### 2. Medium: `generateTextWithReminder` drops the task's tool calls on AI SDK 7

`clients/typescript/src/ai-sdk.ts:49` builds the reminder run's history from `result.response.messages`. In AI SDK 7, `response` is the last step's ("Additional response information from the last step", `ai` 7.0.183 types), and the whole run is `result.responseMessages`. A two-step mock run gives `['assistant']` from the first and `['assistant', 'tool', 'assistant']` from the second.

Scenario: a 25-step task searches, then answers. The reminder turn gets the prompt, the final answer and the reminder, but no search results, so the model has no entry ids to rate and little to write from.

The test (`clients/typescript/test/conversation.test.ts`) checked only that the last prompt holds the task and the reminder. Fixed, with a multi-step test, in #548.

### 3. Low: both reminder helpers remind after a paused run

`clients/python/src/hivemind_memory/langchain.py:47-56` and `clients/typescript/src/ai-sdk.ts:41-53`. A LangGraph or `create_agent` run with a checkpointer and human-in-the-loop middleware returns at an interrupt (`__interrupt__` in the state), with tool calls in the last AI message and no results. AI SDK 7 tools with `needsApproval` stop the same way. If the reminder is due, the helper appends a user message and runs again. That abandons the approval, and most providers refuse tool calls that have no results.

Fix: skip the reminder, without spending it, when the run paused. Fixed in #548.

### 4. Low (docs): `key_locked` is not the admin's doing

Both package READMEs said "The admin locked the key" in the troubleshooting table. A key lock is done by the person behind the agent from the agent portal (CONTEXT.md, Key lock; ADR 0117), and the admin's key replacement clears it. Fixed in #549 with this write-up.

### 5. Nit: the composed `INSTRUCTIONS` differ by a trailing newline

`clients/python/src/hivemind_memory/text.py:28` keeps the skill's trailing newline; `clients/typescript/src/text.ts:17` trims it. No test compared the two composed texts. Fixed in #548.

## Considered and left as they are

- **Oh My Pi bash word split** (`plugins/hivemind/extensions/hivemind.ts:85-86`). A model could hide a tool command from the split (`\mcp__hivemind_hive_search`, a variable, `base64 -d | sh`). Low: under `omp` the launcher already sets `HIVEMIND_MCP_URL=off` and unsets the key, so the plugin's server cannot be reached, and a model told it is incognito has no reason to hide a call.
- **`mcp__hivemind_hive_write --help` counts as a write** for the stop nudge (`tests/unit/test_stop_hook.py:695` pins it). This matters only in a session that never read entries. In the usual flow the agent searches first, so the reminder still comes.
- **OpenAI Responses tools without `strict`** (`clients/python/src/hivemind_memory/formats.py:38`). OpenAI's function calling guide says Responses tries to make a schema strict and falls back to non-strict when it cannot, so the Hivemind schemas with optional arguments are not refused.
- **pid checks in the launcher.** `kill -0` treats another user's process as dead, and a recycled pid of the same user refuses by mistake. The first needs a gateway run as another user on the same home; the second fails closed.

## Checked and fine

- **The reminder rule** in `Conversation` (both languages) matches `hivemind-stop.sh`: once, at or above the threshold, quiet after a rating or after a write with no reads. The threshold parse agrees in all three (only ASCII digits count, else 20).
- **Counting by call id** works with a checkpointer that returns the whole thread, and LangGraph's `add_messages` merges the re-sent history by id.
- **AI SDK options**: `prompt` as text or messages, `messages`, `system`, `stopWhen` and `tools` all carry over to the reminder run.
- **Text sync and drift tests**: `clients/sync_text.py` replaces the setup clause exactly once, and `tests/unit/test_client_packages.py` pins the instructions, reminder and compaction copies and compares every tool argument in both packages with the server's.
- **Exports**: `__all__` and `index.ts` export the same names.
- **`hermes_profile_dir`** picks the right home for `-p`, `--profile`, `--profile=`, `active_profile` and `default`.
- **Docs**: no broken relative link or anchor in the changed Markdown; the SPEC §5.2 anchor the package READMEs link to on PyPI and npm is kept by an explicit `<a id>`. The client READMEs' troubleshooting codes all exist in `src/hivemind/mcp/errors.py`.
- **Tests**: unit suite green; client packages 55 Python and 26 TypeScript tests green before the fixes.
