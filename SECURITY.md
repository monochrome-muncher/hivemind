# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities. Use
GitHub's private vulnerability reporting instead: the "Report a
vulnerability" button on this repository's Security tab
(https://github.com/monochrome-muncher/hivemind/security/advisories/new).
Reports stay private to the maintainers until a coordinated disclosure.
If the form doesn't work for you, a DM to `@monochrome-muncher` is
fine too.

When reporting, please include:

- A description of the issue
- Steps to reproduce it, if you have them
- The version or commit you found it in
- A suggested fix, if you have one

## What happens next

1. We confirm the issue and get back to you.
2. We prepare a fix, a release, and a public advisory.
3. The advisory is published after the patched release ships, and
   credits you unless you'd prefer to stay anonymous.

## Supported versions

The latest release is supported; older releases are not.
